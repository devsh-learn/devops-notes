# devops-notes

My learning notes, cheat sheets and progress log on the way to a junior DevOps / cloud engineer role.

## About

I have experience in server infrastructure and virtualization,
and I am now learning DevOps and cloud engineering.
I practise on an Ubuntu Server virtual machine and build small projects,
each in its own repository.

## Goal

My goal is to get my first job as a junior DevOps / cloud engineer in Poland,
preferably remote.
